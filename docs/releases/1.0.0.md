# Mapperly 1.0

First public release for WoW Forever (Interface 16001).

## Highlights

- Remembered compact and enlarged map views with a clean painted-icon toolbar.
- Standalone inns/mailboxes, dungeon entrances, flight masters and transport markers.
- Per-layer map visibility, custom notes, zone-level labels and player/cursor coordinates.
- Dedicated settings with icon-labelled location rows and live marker-size previews.
- Stable movement opacity and an optional quest pane.
- Coordinate navigation with a movable bearing/distance arrow and painted destination pin.

## Install

Download **Mapperly-1.0.0.zip** below and extract the `Mapperly` folder into `Interface/AddOns`. Restart the game, or `/reload` when updating. Open the map with **M**. Existing settings and notes are preserved.

Use the attached addon ZIP rather than GitHub's automatic source archives. `Mapperly-1.0.0.zip.sha256` contains the archive checksum.

## Notes

Navigation is straight-line guidance, not terrain or transport routing. Portal locations are manual-only. Bundled service data can have gaps or stale records; discoveries supplement it. Compatibility with other addons depends on the installed mix.

Mapperly's original code/artwork uses the MIT license. Bundled third-party libraries and data retain their documented licenses, including the GPL-2.0 service dataset; see NOTICE.md.

Validation: Lua/settings/map/pin/texture regression checks, navigation checks, SQL extractor tests and release archive validation. In-game visual and addon-combination checks remain necessary.
