# Fishing level label — local 1.2.4 build

Install Mapperly-1.2.4.zip and `/reload`. Existing settings, notes and destinations remain in place.

1. View Duskwood: beneath the quest-level line, expect **Fishing: 51+ · Recommended: 150** in white. The native subzone label should sit on a third row without overlap.
2. Hover the fishing line. The tooltip must explain minimum versus reliable-catch guidance, lure bonuses, source/date and that this is published reference data, not a verified live server requirement. Moving away should dismiss it. Clicking/dragging this area should still interact with the map.
3. View Elwynn (1 / 25), Stormwind (1 / 75), Stranglethorn (126–201 / 225–300), Feralas and Azshara (201–326 / 300–425). Hover the mixed-water zones to read the named exceptions. Cities should have fishing data even without a quest-level range.
4. Switch to a continent/world overview, Badlands or a Forever-specific zone without coverage. The fishing line must disappear, with no stale values from the previous map.
5. Check both themes, compact size at 50%, enlarged mode and quest pane open/closed. The fishing line should fit its viewport and stay beneath the zone heading; native hover/subzone captions must have their own space. The Minimal Charcoal fishing line sits just inside the map below its header.
6. Open/change maps during combat and check that the label adds no blocked-action warnings. It reads only bundled data and map identity; it does not inspect aura or tracking state.

Validate the numerical guidance through real fishing observations before treating any threshold as server-confirmed. Successful catches alone cannot prove the exact minimum or guaranteed-catch threshold. Keep pool catches separate from open water. Record special waters and effective skill (including bonuses), not only character/base skill.
