# Fishing hover — local 1.2.5

1. Install Mapperly-1.2.5.zip and `/reload`. On Eastern Kingdoms, hover Elwynn Forest. Beneath its quest-level label, expect **Fishing: 1+ · Recommended: 25**.
2. Hover Duskwood (51 / 150), Stormwind (1 / 75), Stranglethorn (126–201 / 225–300), and Azshara/Feralas on Kalimdor (201–326 / 300–425). The continent itself must not receive a fishing requirement.
3. Move onto Badlands or an unsupported Forever zone, into the ocean, off the map, or over a higher-priority POI banner. The fishing text must clear rather than retaining the previous zone's values. Closing/reopening the map should not flash stale data.
4. Check compact/enlarged view and both themes. Fishing should stay readable below the hovered zone name, without covering native description text. Clicking/zooming the map must still work. Enter a zone map and confirm only its existing fishing heading remains.

The continent-hover fishing row uses larger 14px text and extra spacing; the zone-map fishing text keeps its existing size.
5. The numbers remain published reference guidance, not verified server thresholds. No fishing data or tracking settings changed in this build.

If using controller UI, hover a different zone with the gamepad cursor while leaving the mouse elsewhere. Fishing and quest levels must follow the same native cursor target. Native mouse focus should restore mouse hover normally.
