# Native liquid occupancy and swimming policy

`Data/Water.lua` is generated by `tools/build_water.py` from the existing read-only Forever 1.60.1 build 70959 terrain extraction. It covers all 55 supplied local terrain maps (43 complete indexed terrain and 12 partial); overview maps remain unsupported. Complete means indexed ADT terrain coverage, not verified collision or bridge coverage.

The original extractor is `../Gatherly/tools/build_terrain.py` with `tools/terrain/rules.py`. Native ADT `MH2O` layer extents and occupancy bits mark liquid cells. Each source PNG preserves liquid as 128, missing geometry as 64, permitted ground as 255 and restricted ground as 0. The cleanup algorithm only changes 0/255. The builder verifies every uncompressed PNG SHA256 and dimension against the bundled terrain mask before packing known nonliquid (0/255) cells. It records per-map PNG/native-mask hashes and source generator/rules hashes in `tools/data/water-manifest.json`. The source artifacts remain outside the addon at `../output/terrain-overlays-70959`; the underlying snapshot is `../output/forever-datamine-70959`.

There are 8,959,399 native liquid cells and 1,626,339 unknown cells across these overlapping map views. Counts are map-grid counts, not unique world surface area. Known nonliquid cells still require permission from the existing terrain and ground-correction masks. Missing water data, a mismatched base mask, missing rows and malformed packed bytes never establish dryness.

Swimming is allowed by default and retains the original terrain predicates and baked walking signatures. The dry-first planning attempt applies the additional dry predicate to the full supercover segment, path search, smoothing, approach, validation and live reuse. Dry cache contexts include water rows and cannot use the old allowed-mode baked signature. Ordinary roads do not prove bridges: liquid-occupied cells are conservatively rejected even where an unmodeled bridge may exist. Separately certified native-floor corridors continue through their existing structure interfaces; this grid does not invent bridge floors or override their evidence.

The native source marks all liquid layers conservatively; no character-specific swim depth, dynamic water level, collision surface or runtime bridge identity is inferred. Partial maps retain their explicit unknown coverage. Regenerate and review when the client source build changes.

As of rc.2 the user option is Avoid swimming if possible. Journey planning tries the strict predicate first, then retries under ordinary terrain permissions if no complete dry itinerary is found within the search limits. Temporary dry policy is scoped to its coroutine and never changes live arrival checks or other jobs. Explicit internal allowSwimming=false checks retain strict dryness.
