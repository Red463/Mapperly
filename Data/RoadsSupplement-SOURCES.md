# Native WMO road supplement provenance

`RoadsSupplement.lua` is generated by `python tools/build_road_supplements.py` from `tools/data/native-road-supplements-70959.json`. It supplements road preference only. Terrain permissions and road preference defaults are unaffected.

Stormwind UiMap 1453 already has 2,028 selected ADT texture road cells. The ADT extractor selects filenames containing `road` or `cobblestone`. City paving also exists as WMO geometry using `dungeons/textures/floor/mm_street_02.blp`, FileDataID 127976. The city street selection uses only upward collidable triangles with that exact material and slopes at most 50 degrees. Separately identified static dock groups use the bounded selection described below.

The read-only Forever 1.60.1 build 70959 CASC snapshot supplies city root WMO 7962574, placement 10047 and 20 group files. The pinned source contains 2,349 world triangles, triangle indices, flags, material IDs, group/root hashes and the placement transform proof. The transform matches the native bounding box within 0.000744 yards. Native `MPY2` stores 16-bit flags and material indices; treating these groups as legacy `MOPY` yields no collision candidates. Format reference: [TrinityCore native WMO extractor](https://main.trinitycore.net/d5/d6b/wmo_8cpp_source). No implementation code was copied.

Texture names come from the pinned [wowdev community listfile 202611211242](https://github.com/wowdev/wow-listfile/releases/tag/202611211242). Rasterization uses the original 418 by 279 grid and exact native zone bounds, four samples per axis and at least 25 percent triangle coverage per cell. The city street selection adds 3,533 cells. Eleven separately certified static boarding pier floor triangles add another 53 cells, for 3,586 added cells and 5,614 total. The complete merged mask SHA256 is `fd68449d364b6fbe18f9ad5c2da226f4178e29e0d1f62a5e1b5740a960afcf80`.

The generated record includes exact base rows, their mask hash, original road count, terrain mask hash and grid dimensions. Runtime selection must match the base rows, terrain hash and dimensions before using the merged preference. Stale or missing data must retain the original road mask. The generator independently verifies these bindings, collision flags, triangle orientation and slope before emission. The generated record also pins the source JSON SHA256.

The Stormwind static pier selection uses only the 11 native deck triangles supporting the certified Stormwind boarding pier corridor. It does not select every upward dock face or pylon cap. Root WMO 219576, placement 66886228 and group 219577 are explicitly bound, as are the native placement transform, floor heights and path support/clearance summary. These are fixed shore structures, not a vessel deck.

These 1,501 additional triangles come from native static WMO groups explicitly named `dock` or `pier`, within 100 yards horizontally of an actual native boat stop. Each triangle is collidable, faces upward and has slope at most 50 degrees. All three vertices must already be permitted by the original terrain mask in that zone. Every selection pins native placement parameters, MODF source ADT, root/group hashes, group and triangle IDs, flags, material IDs and world vertices. Four tilted placements were excluded because this bounded audit validates yaw-only transforms. This is a conservative subset of port geometry.

`python tools/verify_road_supplements.py` independently replays all 3,861 selected street/static-dock triangles from the read-only client CASC, including original placement transforms, hashes, collision flags and material IDs. It then verifies original terrain permissions, the 100-yard dock selection bound and exact base mask bindings. `python tests/road_supplements.py` checks deterministic emission, preservation of original roads and rejection of stale or invalid proofs.

Only Stormwind has separately certified access corridors and boarding handoff geometry. Other-port hints do not certify headroom, character clearance, pier connectivity or vessel boarding. The bounded native asset scan found no dock-named candidates for Theramore, Auberdine, Feathermoon, Steamwheedle or Powderfuse; those ports may use M2 or differently named assets. No coverage or absence claim is made for them.

This is a road preference supplement, not a collision mesh or harbour boarding connector. Local harbour collision witnesses and exploratory dock graphs are in `output/road-dock-audit`. No water permissions or guessed shore-to-vessel walking links are included. Native source geometry alone does not certify character clearance, moving-platform boarding or live-client access.
